# Gestor de Calificaciones

## Descripción
Este proyecto consiste en un programa de consola desarrollado en C# y .NET 10, que permite registrar estudiantes, agregar calificaciones y consultar sus promedios.

## Funcionalidades
- Registrar estudiantes con matrícula única y nombre.
- Agregar calificaciones entre 0 y 100.
- Calcular el promedio de cada estudiante.
- Mostrar si el estudiante está aprobado o reprobado.
- Consultar el listado de estudiantes.
- Validar datos incorrectos y matrículas inexistentes.

## Clases del proyecto

**Estudiante.cs:** Contiene las propiedades del estudiante, sus calificaciones y los métodos para calcular el promedio y determinar su estado.

**GestorCalificaciones.cs:** Administra el registro, búsqueda y consulta de los estudiantes, además de permitir agregar calificaciones.

**Program.cs:** Contiene el menú principal y permite al usuario interactuar con las diferentes opciones del sistema.

## Requisitos
- Visual Studio.
- .NET 10 SDK.

## Cómo ejecutar
1. Abrir el proyecto en Visual Studio.
2. Verificar que esté seleccionado .NET 10.
3. Ejecutar con Ctrl + F5.
4. Utilizar las opciones del menú principal.
